# Galveston Digital Twin — geometry audit

Date: 2026-10-23. Generated by `geospatial/validation/audit_geometry.py`.

## Executive summary

The demonstration environment is **real 3D mesh geometry** (OSM2World GLB) draped on **2D satellite/aerial imagery**. Satellite pixels show **photographed rooftops and facades**; they are **not** 3D structure. The GLB is a **single merged asset** (1999 internal meshes) without stable per-building mesh IDs in the viewer, so selection uses the **566-entry footprint catalog**, not ray hits on individual OSM2World meshes.

## Known visual conflicts

1. **Double rooftops**: satellite shows real roofs; GLB draws procedural roofs above the same footprint.
2. **Height homogeneity**: 565 / 566 buildings use default height estimate.
3. **Ground mesh opacity**: full GLB opacity affects buildings and ground together until mesh groups are split in export.
